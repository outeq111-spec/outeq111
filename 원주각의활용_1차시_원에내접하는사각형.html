2. 원주각
② 원주각의 활용

1차시 · 원에 내접하는 사각형의 성질

원에 내접하는 사각형의 성질 · 생각톡

탐구 · 조각을 맞대면 ∠A와 ∠C가 일직선을 이룬다 → ∠A + ∠C = 180°

설명

원에 내접하는 사각형에서 한 쌍의 대각의 크기의 합이 180°임을 설명해 보자.

① ∠BAD, ∠BCD에 대한 중심각을 각각 ∠x, ∠y라 하자.

② 원주각은 중심각의 ½
→ ∠A = ½∠x

③ 마찬가지로 ∠C = ½∠y

④ ∠x + ∠y = 360°이므로
∠A + ∠C = ½ × 360° = 180°

∠A + ∠C = 180°

마찬가지로 ∠B + ∠D = 180°임을 학생에게 말로 설명하게 해 보세요.

정리

원에 내접하는 사각형에서 한 쌍의 대각의 크기의 합은 180°

문제 1 (1)

다음 그림에서 x, y의 값을 구하시오.

① 96°와 y°는 마주 보는 각
→ y = 180 − 96 = 84

② 75°와 x°도 마주 보는 각
→ x = 180 − 75 = 105

답 · x = 105, y = 84

문제 1 (2)

다음 그림에서 x, y의 값을 구하시오.

① 30°, 35°, x°가 있는 삼각형에서
x = 180 − 30 − 35 = 115

② x°와 y°는 원에 내접하는 사각형의 마주 보는 각
→ y = 180 − 115 = 65

답 · x = 115, y = 65

대각선 때문에 사각형의 대각을 찾기 어려워하는 학생이 많습니다. 사각형의 네 꼭짓점을 먼저 짚어 주세요.

문제 2 · 추론

원에 내접하는 사각형 ABCD에서 변 BC의 연장선 위의 한 점을 E라 할 때, ∠A = ∠DCE임을 설명하시오.

① □ABCD는 원에 내접
→ ∠A + ∠BCD = 180°

② B, C, E는 한 직선 위
→ ∠BCD + ∠DCE = 180°

③ ①, ②에서 ∠A = ∠DCE

∠A = ∠DCE

원에 내접하는 사각형의 한 외각의 크기는 그 내대각의 크기와 같다는 사실로 정리해 주세요.

원에 내접하는 사각형의 조건

한 쌍의 대각의 크기의 합이 180°인 사각형은 원에 내접한다. 이를 설명해 보자.

① □ABCD에서 ∠B + ∠D = 180° …… ⓐ

② 세 점 A, B, C를 지나는 원을 그리고, 호 AC 위에 점 E를 잡으면 □ABCE는 원에 내접
→ ∠B + ∠E = 180° …… ⓑ

③ ⓐ, ⓑ에서 ∠D = ∠E
→ 점 D도 원 O 위에 있다.

□ABCD는 원에 내접한다

③은 앞 시간 설명하기(원 안·원 위·원 밖의 점에서 본 각의 크기 비교)를 떠올리게 하면 좋습니다.

정리

한 쌍의 대각의 크기의 합이 180°인 사각형은 원에 내접한다.

문제 3

다음에서 사각형 ABCD가 원에 내접하는 것을 모두 찾으시오.

문제 3 (1)

① 마주 보는 두 각의 합
98° + 82° = 180°

원에 내접한다 ⭕

문제 3 (2)

① △ACD에서
∠D = 180° − 40° − 43° = 97°

② ∠B + ∠D = 80° + 97° = 177° ≠ 180°

원에 내접하지 않는다 ❌

문제 3 (3)

① ∠A = 180° − 55° = 125°

② ∠C = 180° − 125° = 55°

③ ∠A + ∠C = 125° + 55° = 180°

원에 내접한다 ⭕

문제 3의 답: (1), (3). (3)은 한 외각(125°)이 그 내대각 ∠A(125°)와 같다는 것으로도 판단할 수 있습니다.
