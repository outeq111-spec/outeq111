활동 1 · 나만의 암호 설계

암호의 종류도, 규칙도 자유! 막막하다면 이렇게

① 자리 바꾸기

참고: 스키테일

글자를 몇 칸씩 줄지어 쓰고
다른 방향으로 읽기

② 글자 바꾸기

참고: 시저

다른 글자·숫자로 바꾸기
C = 3 × P + 2

③ 신호·기호로

참고: 모스

점·선, 0·1, 나만의
그림 기호로 나타내기

④ 확인 숫자 붙이기

참고: 바코드

암호문 끝에 오류를 잡는
체크숫자 넣기

⑤ 소수 이용하기

참고: RSA

A=2, B=3, C=5 …처럼
소수로 번호 붙이기

⑥ 완전히 새로운 암호

참고: 나만의 것

격자, 달력, 좌표,
여러 방법 섞기 … 무엇이든!

꼭 정하기 ① 암호 이름 ② 암호화 규칙 (말·식·그림·표) ③ 열쇠 ④ 복호화 방법 ⑤ 숨어 있는 수학
→ 활동지 [활동 1] 칸을 채우고, 내 규칙을 다른 사람이 읽어도 이해할 수 있게 써 보세요.
①~⑥은 예시일 뿐 제한이 아니다. 두 가지를 섞거나(예: 자리 바꾸기 후 소수 번호) 완전히 새로운 암호도 환영.

좋은 암호의 조건

열쇠를 가진 사람은 반드시 풀 수 있어야 암호다

조건 ① 서로 다른 글자는 구별되게

"모음(A, E, I, O, U)은
전부 ★로 바꾼다"

CAT → C★T,  CUT → C★T

C★T를 받으면 CAT인지 CUT인지
알 수 없다! ✕

조건 ② 거꾸로 되돌릴 수 있게

계산했다면 → 반대 연산을 거꾸로 순서로
×3 → +2  ⇒  −2 → ÷3

자리를 바꿨다면 → 같은 칸 수로
다시 줄지어 쓰기

양말 신고 → 신발 신기
신발 벗고 → 양말 벗기 🧦👟

스스로 점검 내 암호문을 열쇠만 가지고 다시 풀어 보았을 때 원래 메시지가 딱 하나로 나오나요?
조건 ①은 수학의 '대응'(하나의 글자 ↔ 하나의 암호) 개념과 연결된다.

× ÷ ² 도 입력 가능 (예: 5P−7, P², (P+1)×4)

메시지
학생 식을 입력해 '같은 숫자' 여부를 함께 확인. (P−13)^2 → 쌍으로 겹침, 2P + 나머지 체크 → A와 N이 모두 0 (26 = 2 × 13이므로 곱하는 수는 홀수이면서 13이 아니어야 한다 → 아핀 암호, 러닝페어 심화 주제).

활동 3 · AI와 암호 대화

AI와 암호문을 3번 주고받기

Round 1

해독 도전

규칙은 숨기고 암호문만 보내기

"내가 직접 만든 암호야. 암호문은 MHF AIU TSN이야. 어떤 규칙으로 만들었는지, 원래 메시지가 무엇인지 추리해 줄래? 어떻게 추리했는지도 알려 줘."

Round 2

정확하게 설명하기

규칙을 설명하고 해독 부탁

"내 규칙을 알려 줄게. 메시지를 3글자씩 가로로 줄지어 쓴 다음, 첫 번째 세로줄부터 위에서 아래로 읽었어. 이 규칙대로 풀어 줘. 과정도 보여 줘."

Round 3

AI의 답장

내 규칙으로 암호화된 답장 받아 풀기

"이제 네 차례야. 내 암호 규칙으로 암호화한 짧은 답장을 보내 줘. 원래 메시지는 말하지 마!"

라운드마다 AI의 답을 활동지에 기록하고, 맞았는지 직접 확인하기!
